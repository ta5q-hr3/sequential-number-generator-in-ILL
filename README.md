====================================================
# 連番作成ツール(連番作成ツール.jsx)使用方法
====================================================

Adobe Illustrator用のスクリプトです。
連番テキストを新規作成して整列 or 既存のテキストオブジェクトに割り当てます。


----------------------------------------------------------
## 1. インストール方法(任意。毎回ファイル指定から実行する場合は不要です)
----------------------------------------------------------

### ■ A. ファイル指定からその都度実行する場合
  インストール不要です。「2.実行方法」の(A)の手順で
  そのままファイルを指定して実行できます。

### ■ B. Illustratorのメニューに常時表示したい場合
  「連番作成ツール.jsx」を、以下のフォルダに配置してください。
  (2026年8月の現在最新バージョンでの設定です)

  Windows:
  ```
    C:\Program Files\Adobe\Adobe Illustrator [バージョン]\
    Presets\ja_JP\Scripts
  ```

  Mac:
  ```
    /Applications/Adobe Illustrator [バージョン]/
    Presets.localized/ja_JP/Scripts
  ```

  「ファイル > スクリプト」メニュー内に本ツール名(連番作成ツール)が表示され、クリックだけで起動できるようになります。
  ファイル配置後にIllustratorを起動するか、起動中の場合は再起動してください。
  

  **ショートカットキーを割り当てることができるぞ!**

  上記B.の方法でメニューに登録した後、「編集 > キーボードショートカット」を開き、
  「メニューコマンド > ファイル > スクリプト > 連番作成ツール」を選択することで、
  任意のキーの組み合わせでショートカットキーの割り当てが可能です。
  使用するバージョンで操作内容は異なるかもしれませんが、備忘録まで。。
  (本スクリプトはそんなに頻繁に使用する機能でもないので、他の機能で有用な時に思い出してください)


----------------------------------------------------
## 2. 実行方法
----------------------------------------------------

### (A) その都度ファイルを指定して実行する場合
    1. Illustratorでドキュメントを開く
    2. 「ファイル > スクリプト > その他のスクリプト...」を選択
        ※ メニュー名はIllustratorのバージョンによって異なります
    3. スクリプトファイルの格納場所から「連番作成ツール.jsx」を選択する

### (B) メニューに登録済みの場合
    1. Illustratorでドキュメントを開く
    2. 「ファイル > スクリプト > 連番作成ツール」を選択する

### (C) ショートカットキーを割り当て済みの場合
    1. Illustratorでドキュメントを開く
    2. 割り当てたショートカットキーを押す


----------------------------------------------------
## 3. 使い方(ダイアログの操作)
----------------------------------------------------

スクリプトを実行するとダイアログが表示されます。
まず上部の「モード」を選択してください。
(新規に連番オブジェクトを作成 / 選択中のテキストに連番を割り当て)

### ■ モード1:新規に連番オブジェクトを作成
  アートボード上に新しく連番のテキストを生成します。
  チケットや番号札などの作成時に最初に使用しておくのがおすすめです。

  [番号設定]
   * 開始番号   :最初の数字 (例: 1)
   * 個数      :作成する連番の数 (例: 10 → 10個のテキストオブジェクトを作成します)
   * 増分      :1つ進むごとの増加量 (例: 1、2  1を設定すると1,2,3... 2を設定すると2,4,6...）
   * 桁数      :ゼロ埋めしたい桁数(例: 3 → 001,002...)
             0を指定するとゼロ埋めなし(デフォルト)
   * 接頭辞     :番号の前に付ける文字(例: "No.")
   * 接尾辞     :番号の後に付ける文字(例: "番")

  [配置設定]
   * フォントサイズ:生成するテキストの文字サイズ(pt)
   * 間隔      :隣同士のテキストの間隔(pt)
   * 方向      :横並び / 縦並び / グリッドから選択 (生成するテキストオブジェクトの並び方向)
   * グリッド列数 :「グリッド」を選んだ場合の1行あたりの個数

  設定後「実行」を押すと、アクティブなアートボードの左上付近を起点に連番テキストが自動生成されます。

### ■ モード2:選択中のテキストに連番を割り当て
  すでにIllustrator上に配置済みのテキストオブジェクト(座席番号やラベルなど)に、
  まとめて連番を割り振ります。
  ** 配置済みのテキストの中身は書き変わりますのでご注意ください ** 

  手順:
   1. 番号を入れたいテキストオブジェクトをあらかじめ配置し、
      すべて選択した状態でスクリプトを実行します
      (選択順は問いません。位置関係から自動で並び替えます)
   2. モードで「選択中のテキストに連番を割り当て」を選択する
   3. 開始番号・増分・桁数・接頭辞・接尾辞を設定する
   4. 「実行」を押す

  ※ 選択オブジェクトは「上→下」「同じ高さなら左→右」の順に自動的に並び替えてから番号が振られます。
  ※ 選択範囲にテキストオブジェクト以外(図形など)が含まれていても、テキストオブジェクトのみが対象になります。
  ※ 実行すると既存のテキストの中身は連番の文字列に置き換わります。
    (元の文字は失われるため、必要であれば事前にコピーを取っておいてください)


----------------------------------------------------
## 4. 注意事項
----------------------------------------------------

* 実行前に必ずドキュメントのコピーを保存しておくことをおすすめします
  (既存オブジェクトへの連番割り当てはテキストの中身を上書きするため)

* 「新規作成モード」で生成される位置はアクティブなアートボードの左上基準です。

  新しいアートボードを用意しての利用がおすすめです。
* *フォントは指定していないので、Illustrator側のデフォルトフォントで作成されます。

* グリッド生成の場合、Gap間隔がテキストオブジェクトごとの左端を起点に算出されるので、文字列が長いと重なってしまいます。Gapは大きめに設定してください。
